# MoyNormativ
iOS-приложение «Мой норматив» — личный трекер физических нормативов. SwiftUI, SwiftData, CloudKit.
## О приложении
**MoyNormativ** помогает отслеживать прогресс в выполнении физических нормативов по возрастным ступеням. Пользователь вводит свои результаты, а приложение сравнивает их с нормативами и присваивает знак отличия: бронза, серебро или золото.

### Возможности

- 👤 **Профиль пользователя** — имя, дата рождения, пол, возрастная ступень
- 🏅 **Специальные категории** — нормативы для людей с ОВЗ (слух, зрение, ОДА)
- 📊 **Ввод результатов** — по каждому испытанию с учётом единиц измерения
- 🥇 **Автоматический расчёт знака** — бронза / серебро / золото по каждому тесту
- 📈 **Прогресс и статистика** — сколько сдано из общего количества
- 🕓 **История результатов** — с группировкой по датам
- 🔗 **Шаринг результата** — карточка с медалью в PNG
- ☁️ **iCloud-синхронизация** — данные доступны на всех устройствах пользователя
- ⚙️ **Настройки** — сброс данных, экспорт, информация о приложении

## Технологии

- **SwiftUI** — декларативный UI
- **SwiftData** — локальное хранилище результатов
- **CloudKit** — синхронизация через приватную базу iCloud
- **Observation** (`@Observable`) — реактивные Store-объекты
- **Swift Concurrency** — `@MainActor`, async/await
- **ImageRenderer** — генерация карточки результата для шаринга

**Требования:**
- iOS 17.0+
- Xcode 15.4+
- Swift 5.9+
